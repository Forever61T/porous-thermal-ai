# Historical No.1 results

Only this project's synthetic No.1 rows/plans from the earlier five-seed
feasibility experiment are retained. All external No.2 rows, sample identifiers
and paper records were excluded before public history was initialized.

The Phase3 runner uses the copies in `results/tables/` to check unchanged model
predictions against comparable earlier runs. This is provenance, not a second
training dataset. The old 4.881 -> 1.630 result remains historical; the final
10-split result is 4.817 -> 1.657.
